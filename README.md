# Bike Sales Data Analytics Dashboard

## Project Overview
This project focuses on analyzing bike purchase data using Microsoft Excel. The objective is to explore customer demographics, purchasing behavior, and identify patterns that influence bike purchases.

## Dataset
The dataset contains customer information such as:
- Gender and marital status
- Income and occupation
- Education and home ownership
- Number of children and cars
- Commute distance
- Age and purchase behavior

## Excel Skills Applied
- Data cleaning and formatting
- Data transformation and standardization
- IF statements and nested formulas
- Age-group categorization
- Pivot tables
- Data analysis and visualization
- Dashboard creation

## Project Structure
- `bike_buyers`: Original dataset
- `Working sheet`: Cleaned and transformed dataset
- `Pivot Table 1`: Pivot-table analysis
- `Dashboard`: Visual representation of key findings

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Charts and Data Visualization
